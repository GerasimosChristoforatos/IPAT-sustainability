# data/raw

Unmodified source files. Provenance, commit pins and SHA-256 hashes are in `../sources.yaml`.

- `owid-co2-data.csv` is not committed (15 MB); `make fetch` downloads the pinned commit and verifies its hash.
- `papers/` holds article PDFs used to read specific tables. It is git-ignored (copyright).
- Data files supplied by hand (WHR, UN WPP) go directly in this folder.
